# Yana Runner — Путешествие по миру 🌍

Браузерная раннер-игра: маршрут из четырёх городов, проходится строго по порядку.

**Играть:** https://REPLACE-ME.github.io/yana-runner/

## Локальный запуск

Открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Структура

- `index.html` — разметка экранов (меню, игра, результаты)
- `game.js` — игровая логика
- `style.css` — стили
- `assets/` — фото и саундтрек
