# Yana Runner — Путешествие по миру 🌍

Браузерная раннер-игра: маршрут из четырёх городов, проходится строго по порядку.

**Играть:** https://monkate.github.io/yana-runner/

## Локальный запуск

Открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Структура

- `index.html` — разметка экранов (меню, игра, результаты)
- `game.js` — игровая логика
- `style.css` — стили
- `assets/` — фото, саундтрек, ролики гостей и финальная открытка

## Поздравления

После каждого города снизу выпрыгивает говорящая голова с голосовым: Карина
(Дербент), Наташа (Москва), Настя (Тель-Авив), Катя (Амстердам). Ролики —
анимированный WebP: его прозрачность, в отличие от альфа-канала в WebM,
понимает и Safari. Все сведены к одному холсту, чтобы на экране гостьи были
одного размера. В финале — поздравительная гифка во весь экран с фейерверками.
